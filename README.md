# extract-next-terminal-new
提取新版的next-termianl到chroot

## 安装方法

1. 下载最新的release到服务器
2. 解压下载的next-terminal的压缩包
3. 按照你的postgresql来配置后台数据库
4. 按照你的配置修改next-terminal下的config.yaml
5. 在next-terminal的目录下面，使用./next-terminal -c ./config.yaml启动服务
